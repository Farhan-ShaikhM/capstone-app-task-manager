# Task Manager – Frontend

React + Vite frontend for the Task Manager. It connects to the Express API in `../server`.

Copy `.env.example` to `.env` so `VITE_API_URL` points at the backend.

## Setup

```bash
npm install
npm run dev
```

The app runs at http://localhost:5173. Make sure the backend is running first (see the main [README](../README.md)).

## Scripts

| Command | Description |
|---|---|
| npm run dev | Start the development server |
| npm run build | Build for production |
| npm run preview | Preview the production build |
| npm run lint | Run ESLint |
